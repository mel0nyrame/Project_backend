# Student Score Management — Frontend

This directory contains the Vue 3 + Vite dashboard for managing students, courses, and scores. It is part of the unified repository; the Spring Boot API lives in the repository root.

## Development

```bash
npm install
npm run dev
```

The frontend expects the API at `http://127.0.0.1:8080` by default. To use another API URL, copy `.env.example` to `.env.local` and set `VITE_API_BASE_URL`.

For the complete project setup, see the [root README](../README.md) or its [Chinese version](../README.zh-CN.md).
